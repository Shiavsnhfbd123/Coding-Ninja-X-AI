FINAL MODEL INFORMATION
=======================

Checkpoint file
---------------
best_model.pth

Architecture
------------
torchvision.models.resnet18(weights=None), trained from random initialization.
The final classification layer is Linear(512, 6). No pretrained weights were used.

Classes
-------
Number of classes: 6
0 = buildings
1 = forest
2 = glacier
3 = mountain
4 = sea
5 = street

Input and normalization
-----------------------
Input size: RGB 150 x 150 pixels
Resize: deterministic resize to 150 x 150 for validation/inference
Normalization mean: [0.485, 0.456, 0.406]
Normalization std:  [0.229, 0.224, 0.225]

Validation result and selection
-------------------------------
Best training-time validation accuracy: 77.75% at epoch 48
Independent saved-checkpoint validation accuracy: 77.83% on 1,200 images
The checkpoint is the best validation checkpoint, not the final epoch weights.

Training configuration
----------------------
Total epochs run: 70
Batch size: 32
Random seed: 42
Optimizer: SGD with Nesterov momentum (momentum=0.9)
Initial learning rate: 0.015
Learning-rate schedule: 5-epoch linear warm-up followed by cosine decay
Weight decay: 0.0005
Loss: CrossEntropyLoss(label_smoothing=0.05)
Training data: 600 original labeled training images only
Validation data: supplied frozen 1,200-image validation split
Test data used for training/model selection: no
Undefined pool images used for training: no

Training augmentation
---------------------
Resize to 150 x 150, random horizontal flip (p=0.5), RandomAffine
(degrees=8, translation=5%, scale=0.90-1.10, shear=4), and ColorJitter
(brightness=0.12, contrast=0.12, saturation=0.08, hue=0.03, p=0.50).

Loading for inference
---------------------
Use final_inference.py in the project root to reproduce submission inference.
The checkpoint is a PyTorch dictionary with these essential keys:
  model_kind = "resnet18_linear_head"
  model_state_dict
  class_names
  image_size
  normalization_mean
  normalization_std
  best_epoch
  validation_accuracy
  training_args

Minimal Python loading outline:
  import torch
  import torch.nn as nn
  from torchvision import models
  checkpoint = torch.load("final_model/best_model.pth", map_location="cpu", weights_only=False)
  model = models.resnet18(weights=None)
  model.fc = nn.Linear(model.fc.in_features, len(checkpoint["class_names"]))
  model.load_state_dict(checkpoint["model_state_dict"])
  model.eval()

Reproducibility
---------------
The exact training arguments and class/configuration metadata are embedded in
best_model.pth. The final submission was generated only after model selection
on validation and has 1,800 rows in the original sample-submission ID order.
